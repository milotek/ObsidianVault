- So for the SWI, we're continuing work on the AGSA client emulator inside of it for testing Silk.
	- Just to re-explain for those unfamilliar, this will let web developers (such as those who work on AIM) test that silk services work correctly without having to boot up an emulator or use a real device every time.
- Design doc has been written.
- It's been extended so that it will be able to be used in conjunction with an emulator or real device. 
	- Say AIM developers introduce a new silk method or event, and the code for that is on GWS but not AGSA, they can choose to only emulate a client response for that particular new method, but all other method calls will go to the real client.
- Implementation in progress, should be complete this month.
