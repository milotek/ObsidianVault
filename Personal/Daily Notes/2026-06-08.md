## Prompt
I am looking to add a new feature into the Silk Web Inspector. I want to replace the Cyberchef link generation with Protoshop links first, in this format:

**[https://protoshop.corp.google.com/embed?type=search.frontend.silk.apis.haptics.PlaySystemHapticRequest&protobytes=CAcQAg==&tabs=viewer,editor&viewerFontSize=12&viewerCondensedSpacing=true](https://protoshop.corp.google.com/embed?type=search.frontend.silk.apis.haptics.PlaySystemHapticRequest&protobytes=CAcQAg==&tabs=viewer,editor&viewerFontSize=12&viewerCondensedSpacing=true)**

where `type=`is the proto package and `protobytes=`is the proto url safe b64 encoded data.

Here's the current function:
```ts
  private generateCyberchefLink(input: string | undefined) {
    // Encodes the input string in base64 and removes any padding characters(https://developer.mozilla.org/en-US/docs/Glossary/Base64).
    return input
      ? "https://cyberchef.googleplex.com/#recipe=From_Base64('A-Za-z0-9-_',true,false)Protobuf_Decode('',false,false)&input=" +
          btoa(input).replace(/=*$/g, '')
      : '';
  }
```

This needs to be changed and we need to get the services from all_services.json / aggregated_services in order to do this, because we'll need to supply the package name along with the proto data (we have the latter, not the first, we should be able to map method and event names to their proto packages using this file, and then we can generate the link given we have those two bits of info.

Protobytes can be url safe b64. Make a new file called proto_service.ts and within it make a function to return the package name given the api name and method/event name. then you can use that inside of generate link function.

yep that works  

genrule(  
    name = "aggregated_services",  
    srcs = ["//search/frontend/silk/apis/{}:service.json".format(p) for p in subpackages(include = ["*"]) if p != "onepresence"],  
    outs = ["all_services.json"],  
    cmd = "echo '[' > $@; first=1; for f in $(SRCS); do [ $$first -eq 0 ] && echo ',' >> $@; cat $$f >> $@; first=0; done; echo ']' >> $@",  
)
