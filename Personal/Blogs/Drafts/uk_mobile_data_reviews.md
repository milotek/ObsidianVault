# Milo's Anecdotal mobile provider experiences

I have commuted along the Cambridge-London train line for about 3+ years now. My biggest frustration during that time was the fact that a lot of mobile service providers had abhorrent signal along this track. It makes it impossible to be productive (combined with the terrible fucking trains, too).

So, here are my lovely reviews for all 4 mobile providers I've ever used in my lifetime. I'm only reviewing them based off the best value for mobile data, primarily in terms of signal.

Personally, I use about 20-30~ GB of data a month, so I typically expect to pay about £10. I've only ran out of data once.
